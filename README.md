## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação web responsiva criada com **HTML5 e CSS3 puros**, focada em semântica, desempenho e boa experiência visual (tema dark com destaques em amarelo). 

### ⚡ Funcionalidades
- **Navegação Sticky:** Navbar fixa no topo com navegação suave entre as seções.
- **Design Responsivo:** Adaptado para diferentes tamanhos de tela (Desktops, Tablets e Celulares).
- **Seções detalhadas:** Apresentação pessoal, biografia, projetos em destaque, habilidades técnicas e redes de contato.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização, layout flexível (Flexbox), animações com hover e media queries para responsividade.
- **Google Fonts:** Tipografias *Orbitron* e *Share Tech Mono* para visual tech/cyberpunk.
